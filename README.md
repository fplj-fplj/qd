# 起点 App 逆向脱壳/算法复现工作区

> 核心思路：先让它跑起来，再逐层拆、逐值对。

## 四步走

1. **摸数据流**
   - 先抓包定位加密入口：密文、密钥、iv、盐值是否都下发到客户端。
   - 确认加密发生在客户端后，就可以在本地完整还原。

2. **绕防护**
   - 环境检测通常是“多层 && 组合”判断。
   - 需要连属性描述符一起 patch，单点 bypass 无效。
   - 工具建议：Frida + objection + Magisk 隐藏模块。

3. **识算法**
   - 认常量：
     - `0x63`（`99`）通常对应 AES。
     - 有初始化向量（IV）通常对应分组对称算法或 Hash/HMAC 加盐。
     - 有置换表（S 盒/P 盒）通常是 DES/3DES 或自定义查表变换。
   - 标准算法直接用现成库（CryptoJS / pycryptodome），不要手写。

4. **拆黑盒**
   - 混淆壳本质常是“查表 + 异或 + 乘法”。
   - 剥壳后对核心函数插桩。
   - 用 Node 跑原版 JS 取中间值，Python 逐值比对，直到逐字节一致。

## 三个最容易踩的坑

- **位运算**
  - JS `>>>` 是无符号右移，Python 要写成 `(x & 0xFFFFFFFF) >> n`。
  - 所有运算注意截断到 32 位：`x & 0xFFFFFFFF`。

- **查表索引**
  - `& 252` 这类掩码隐藏了移位，实际索引往往比直觉差 2 位。
  - 遇到查表先确认索引是 `byte >> 2` 还是 `byte & 0xfc` 等。

- **多层解密**
  - 加密可能叠了好几层，甚至同一层解密两遍才得到明文。
  - 不要把“解出一段可读字符串”当成终点，要对比完整字节流。

## 下一步需要提供的材料

开始实际逆向前，建议把以下内容放到本目录：

- 目标 APK / 解包后的 DEX、so、assets 中的 JS bundle
- 一个真实的“明文 + 密文 + 密钥/IV”样本（用于对拍）
- 抓包得到的请求/响应样例
- 可疑的加密代码片段或堆栈截图

拿到样本后按顺序执行：

```bash
# 1. 先静态定位加密函数/常量
# 2. 再动态插桩取中间值
# 3. 最后用 Python 写离线复现并逐字节对拍
```
